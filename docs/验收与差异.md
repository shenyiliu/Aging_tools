## 当前架构差异

宿主单独写入状态，通过限定当前用户的命名管道启动 Worker；两层 Windows Job Object 管理 Worker 和所属引擎，宿主退出或停止均关闭所属进程树。重启与交互视频留在宿主。已交付同名兼容 EXE；旧斜杠参数转换成单项队列，指定项目结果投影回旧日志，但需在新面板选择开始，不是旧主程序的无人值守替换插件。原 Test.exe 并行运行时不放行真实队列；重启和状态写入由新宿主管理。

主工具条保留功能测试、老化、工具箱及 SN/KEY 入口；左侧“退出”替代超范围的出货封装。设置只实现所选老化业务，不包含订单/OA3。运行面板为统一详情窗口，原版各独立压力包装器窗口暂无可对照样本。

修正原版 1/4 检查失效、错误计数分裂、按名称误杀和重复续测。不关闭 UAC、不清空 System 日志、不修改公共桌面、不执行 Sysprep。当前没有修改电源方案、音量和亮度，因此无需为这些项目创建恢复快照。

真实压力测试执行阶段不提供暂停；倒计时与模拟任务支持协作暂停。用户停止记为 Aborted，所有中止/结果不确定都不能产生 PASS。自动完成动作先保存“已领取”标记，崩溃后不会再次执行；未执行完成动作须人工处理。

系统事件检查采用时间范围，尚未按持久 RecordId 书签实现；WMI 设备枚举与原版 CM 接口接近但不是完全同一过滤集合。电源能力由 SYSTEM_POWER_CAPABILITIES 获取，最终结果还要求系统进入/唤醒事件。

## 专机执行顺序

1. 从完整发布目录启动，确认模拟队列、日志、五个窗口和无开发环境运行。收集分辨率及 DPI。
2. 手工配置工具路径；先用单项 Reboot 3 次，关闭设备/WLAN/耗时检查。管理员注册登录续测任务，完成每次登录后确认一次且仅一次计数。再验证 50 次、只重开程序和意外断电路径。
3. 逐个 S3/S4/CS 验证能力、PwrTest 原始输出和 System 事件；不支持项必须失败。先 3 次再 50 次。
4. 打开设备/WLAN 检查，制造设备移除/状态变化、无热点和无位置权限，检查错误日志。
5. BurnIn 9.2.1006 模式 0 的原始失败报告已保留；继续定位磁盘异常，验证隔离副本、模式 1/2、停止和提前退出。FurMark/3DMark 需取得实际引擎、命令行与原始报告，缺失时不放行。
6. 真实视频：开始/循环/解码失败/P/F/关闭；Core Temp 温度接口取得真实样本后实现桥接。
7. 核对所有旧文件、截图差异及完成/取消/异常路径，再做 24/72 小时完整队列。
