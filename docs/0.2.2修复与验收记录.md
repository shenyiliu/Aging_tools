# 0.2.2 修复与验收记录

日期：2026-11-10。验收环境：当前 Windows 11 原生 x64 主机。结论限于下列场景，不代表所有机型、全部模块、真实电源及长稳已经通过。

## 故障与修复

原保存队列含重启、S3 等项目。旧启动流程一次预检全队列，未预先保存登录续测时各项目重复报错；本机 S3 不支持又阻断其他项目。0.2.2 增加本轮项目选择、依赖/能力逐项检测和管理员重新打开入口。选择不改变原保存队列。含重启时在最终确认后自动注册、验证登录续测，再保存启用设置；注册失败不启动负载。执行前再次检查依赖。

未执行项单独记录于快照、确认、面板和旧式日志，部分执行只显示已选项通过。检测中关闭窗口和重复释放资源已由 E2E 覆盖。发布演练还修复了用户已开正式程序时被单实例提示框阻塞的问题，使用独立数据目录对应的演练锁，正式程序仍保持每用户单实例。安装不自动运行压力、电源或注册续测。

## 尚未完成的实机范围

本机不支持 S3；只读能力检测支持 S4/CS，不等于已执行实测。真实重启/睡眠验收待单独授权。未执行风扇/EC 控制或最大音量恢复测试。FurMark/3DMark 实际引擎仍缺失，不能执行；BurnIn 自带图形负载的 PASS 不代表这两个独立模块通过。CPU 温度、新主板风扇、多型号、Windows 10、不同驱动、DPI 和长稳仍需对应机器验收。

## 复现命令

- scripts/build.ps1：构建并运行两组单元测试。
- scripts/verify-e2e.ps1：运行软件 E2E，使用独立数据目录，不执行电源和风扇操作。
- scripts/verify-e2e.ps1 -Hardware：额外运行真实六分钟负载，仅在已授权的测试机上使用。
- scripts/verify-release.ps1：检查发布文件哈希及模块入口。
- scripts/verify-installer.ps1：隔离安装、升级、运行中保护、数据保留和卸载验证；检测到已有真实安装会拒绝覆盖。
- scripts/build-zip.ps1：打包安装程序及说明，并生成校验清单。

## 安装验证边界

本机已正式安装 0.2.1。安装生命周期测试检测到该安装后按保护规则拒绝继续，未替换或卸载现用程序，不能把本轮安装/升级/卸载记为通过。发布程序检查覆盖八个模块入口、全部文件哈希、隔离界面演练，以及两个通过实际发布 EXE 的 Worker 测试。ZIP 校验脚本检查内外哈希、六个文件、解压后的安装器版本与一致性；它不代替安装生命周期测试。对应结果在 artifacts/verification，安装受阻记录为 installer-0.2.2-blocked.json。
