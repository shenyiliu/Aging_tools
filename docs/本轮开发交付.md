# 本轮开发交付

2026-11-10；GW 老化测试工具 0.1.0 开发预览版。

## 使用入口

- 可运行发布目录：`../artifacts/GW_AgingTool_win-x64/`；双击 `Test.exe`，点“老化测试”。默认模拟，不执行真实硬件动作。
- 源码解决方案：`../AgingTool.slnx`；.NET 10 / C# / WinForms，核心、Windows 适配、界面和测试分层。
- 操作与构建说明：`../README.md`；未完成模块与专机顺序：`验收与差异.md`。
- 发布目录约 125 MB，自包含 x64，无需在目标机安装 .NET；第三方引擎单独配置。

## 已实现的工作

底部工具条、队列编辑/排序、旧配置导入/导出、参数校验、模拟模式、顺序调度、暂停/继续/终止、失败停止、原子 JSON 检查点与备份、真实重启启动 GUID 去重、切项重启规则、PwrTest S3/S4/CS 适配、设备/WLAN/System 事件探针、当前用户登录续测任务、Worker 管道与进程树管理、压力引擎冻结配置和真实报告判定、WMP 视频人工 P/F 与逐次时长、历史日志查看与采样图。

同名 EXE 入口已生成；旧 CLI 转成单项队列并能按原项目序号投影结果，需从新面板开始，不是旧 Test.exe 的无人值守替换插件。
