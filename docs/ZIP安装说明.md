# GMK 老化测试工具 0.2.5 ZIP 安装说明

完整解压 ZIP 到本地文件夹，运行 GMK_AgingTool_Setup_0.2.5_win-x64.exe，按向导安装并从快捷方式启动。ZIP 内是安装程序，自带 .NET 运行时，无需安装开发环境。

适用 Windows 10 22H2 / Windows 11 原生 x64。当前机完成 Windows 11 x64 验收，Windows 10 和其他机型仍需分别验证。可选当前用户或所有用户安装。真实老化是否可运行取决于对应硬件、组件、驱动和权限。

## 0.2.5 启动和预检修复

不再要求启用登录续测，也不再访问登录计划任务。修复启动时任务不存在引发的 0x80070002。依赖预检仅检查各项目自身组件和系统能力，不再把续测条件重复报到所有项目。旧配置和检查点可继续读取。

## 0.2.4 安装错误 32 修复

安装前会逐项检查已有文件是否可替换，发现占用时在复制文件前停止，显示具体路径与错误码。请勿在旧安装器里跳过文件。若旧目录被系统服务长期占用，可在安装目录页选择新的空目录，例如 C:\Program Files\GMK Aging Tool；配置和日志仍从原用户数据目录读取。不要仅因文件占用而删除用户数据，也不要强制结束不明系统进程。

## 0.2.3 名称与标识

软件名称为“GMK 老化测试工具”，使用 GMKtec 官网原始 Logo 和 favicon。更新主界面、电源窗口、托盘、程序图标、安装程序图标、安装向导和快捷方式；原有配置与升级标识继续沿用。0.2.2 修复验收记录为此前功能测试证据，0.2.3 的单元测试、软件 E2E 和发布验证另存仓库 artifacts/verification。

## 使用与升级

首次队列含原版 50 次电源测试和一小时 BurnIn。开始前核对次数、时长和本轮选项。只做负载短测时可选择 BurnIn，关闭切项重启和下次开机开始。安装不会自动执行老化。

安装前结束任务并退出程序。升级保留 %LOCALAPPDATA%/GW.AgingTool 中的配置、日志和检查点，不改已有自选引擎路径；如路径仍指向旧开发目录，请重新匹配本安装 Tools。不要跨机器复制活动检查点续测。

演练只验证软件流程，不判定硬件通过。真实重启/睡眠、风扇控制、最大音量恢复、多机型兼容及长稳仍需实机验收。本机不支持 S3；CPU 温度仍可能未获取。

ZIP 内 SHA256SUMS.txt 提供 EXE 和说明文件的 SHA256；ZIP 自身校验另存为同名 .zip.sha256 文件。
