# GMK 老化测试工具 0.3.4 ZIP 安装说明

完整解压 ZIP，运行 GMK_AgingTool_Setup_0.3.4_win-x64.exe，按向导安装后从快捷方式启动。软件默认请求管理员权限，按 Windows UAC 提示授权后打开；普通账户需提供管理员凭据。自带 .NET 10 运行时，无需开发环境，安装不会执行老化或登记续测任务。

目标系统为 Windows 10 22H2 / Windows 11 原生 x64；当前机器验证为 Windows 11。安装包包含独立 Tools，不要求保留桌面 GW_TEST。

1. 升级前结束当前测试并退出软件。原目录文件被占用时，安装器会在替换前停止并指出路径；释放占用或选新的空目录。
2. 打开“老化测试”，检查队列、次数、时长和逐项依赖，明确选择本轮执行范围。负载短测关闭切项重启、下次开机开始，并检查最大音量选项。
3. 含跨重启流程时，在确认开始后登记当前 Windows 用户计划任务；进入该用户桌面后自动继续，无需软件账号。完成或终止后移除。旧 GUID 格式的待重启检查点需保留日志并新建任务，不能因升级而误增周期。
4. FurMark 正式使用需获授权的官方 1.30.0.0 引擎；安装包未分发该引擎。3DMark 需匹配引擎及有效商业命令行授权。设置页选择对应可执行文件，缺失项目显示未就绪。
5. 配置、检查点和日志在 %LOCALAPPDATA%/GW.AgingTool，升级和卸载保留用户数据。原安装自带路径会迁移，显式外部路径保留。不要跨机复制活动检查点。

2026-11-12 本机 BurnIn 三模式真实短测分别为 FAIL / PASS / PASS，综合模式原始 DirectX 错误如实保留。0.3.4 在 0.3.3 的图片释放、首次兼容性报告、电源参数、防空闲睡眠、重启识别修复和独立 DDR Test 基础上，增加默认管理员启动；2026-11-13 目标 EVO-X2 的逐项实际结果见《目标机测试与修复_20261113.md》，该报告记录的硬件实测版本为 0.3.3。S3 依赖固件支持；风扇、人工视频观感及多机长稳仍待验收，历史版本文档只代表历史版本。
