# 安装与多机型部署（0.2.5 复刻开发版）

先完整解压 GMK_AgingTool_Setup_0.2.5_win-x64.zip，再运行其中的 EXE，可选全用户或当前用户安装。适用 Windows 10 22H2 / Windows 11 原生 x64，自带 .NET 10。Windows 10 为目标支持系统，本轮实际验收系统为当前 Windows 11 x64；其他系统和每种硬件/驱动组合仍需验收。

安装包含自己的 Tools：313 个清单组件文件，包括本轮实际测试通过的 BurnIn 9.2.1006.0、PwrTest、Core Temp、视频、SFT、风扇方案和资源。无需保留原 GW_TEST 目录。另附原包装器及重装引擎参考备份。FurMark/3DMark 实际引擎仍缺失，包装器和场景定义不能代替引擎，缺失项会显示未就绪。第三方许可和目标机授权仍须符合各工具要求。

1. 检查本机项目、次数和时长。初始原版队列含 50 次电源测试和一小时 BurnIn，先按本次用途调整。
2. 点击底部“老化测试”，逐项检查能力和依赖。修复未就绪项，或明确取消勾选；“只选可运行项目”只更改本轮，不改已保存队列。
3. 负载短测可只选 BurnIn，关闭“按原规则切项重启”“下次开机开始”，按需要关闭最大音量。检测结果就绪后点击“开始真实老化”并核对最终确认。
4. 电源及 BurnIn 等项目需管理员权限；窗口提供重新以管理员打开的按钮。含重启/切项重启时保存检查点；开机后手动打开工具并点击“恢复任务”。不配置登录计划任务。
5. 未执行项目会显示在确认、面板和日志中，结果只代表本轮选中范围。菜单中的演练不执行硬件，不计硬件 PASS。
6. 每个型号/系统镜像/驱动组合分别完成短测、支持的电源项目 3 轮和 50 轮，以及长稳，保留原始报告。

本机 S3 不受支持，不能用 CS 冒充；S4/CS、风扇、最大音量恢复尚未实机验收。Core Temp 旧组件可能不支持新 CPU，无有效传感器时显示未获取。视频依赖 WMP ActiveX 和解码器。IP3/WB/Ed 风扇只适用于对应主板，显式选择后会控制硬件。

本轮 85 项单元测试、5 项软件 E2E 通过，并已完成 6 分 02 秒真实 BurnIn 综合测试、所有启用项目 0 错误。软件 E2E 的视频 FAIL/停止结果是预期断言，不是硬件通过。详见《0.2.2修复与验收记录》。这些结果不代表完整 1:1、所有机型或长稳通过。

用户数据在 %LOCALAPPDATA%/GW.AgingTool。先结束任务并退出，再升级。固定 AppId 升级保留配置、日志和检查点；卸载保留用户数据，只清理本安装的续测任务及程序。升级保留已有自选路径，请核对其是否仍指向旧开发目录，必要时重新匹配安装目录 Tools。不要把 active-run.json 复制到其他机器续测。
