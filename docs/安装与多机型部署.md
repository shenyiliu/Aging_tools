# 安装与多机型部署（0.3.4）

运行 GMK_AgingTool_Setup_0.3.4_win-x64.exe，可选当前用户或所有用户安装。目标 Windows 10 22H2 / Windows 11 原生 x64，自带 .NET 10；已在本机与 GMKtec EVO-X2 验证 Windows 11。安装自带老化专用 Tools，不依赖桌面原 GW_TEST。

主程序及七个模块入口默认请求管理员权限，快捷方式、安装完成页和直接双击启动遵循 Windows UAC 授权；取消授权不会运行程序。普通账户启动需提供管理员凭据，数据归属于实际运行账户。命令行探针及自动化调用请使用已提权环境；登录续测保持绑定用户的最高权限计划任务，不启用自动登录或关闭 UAC。当前用户安装的卸载流程也会请求管理员权限来清理续测任务；拒绝授权会保留安装，避免留下失效任务。

组件来源和逐文件 SHA256 在 Tools/reuse-manifest.json；FurMark 官方冻结版本来源另在 Tools/FurMark/engine-manifest.json。FurMark 商用/打包许可未提供，因此安装包不含该引擎。3DMark 引擎与有效商业 CLI 授权待用户提供。原包装器仅作为行为参照，不承担生产调度；SFT 功能程序、软件账号和 SN/OA3 入口已移除。

1. 核对本机可执行项目、次数与时长。初始队列沿用原 INI，不要直接将多轮电源和长稳队列用于办公机。
2. 从“老化测试”进入逐项预检，明确选择本轮项目。只选可运行项目仅影响本轮，未执行项单列且不计通过。
3. 负载短测关闭切项重启、下次开机开始，检查最大音量。软件启动时默认请求管理员权限。普通使用只选路径，无需编辑引擎 JSON。
4. 跨重启流程在最终确认后注册当前 Windows 用户、InteractiveToken、最高可用权限的计划任务，无密码、无需软件账号；进入该用户桌面后继续。任务与运行 GUID、安装 EXE、数据目录、SID、内核启动事件标识绑定；同一启动不累加周期。完成或终止后删除任务。不要在活动运行期间移动安装和数据目录。
5. 各型号/系统镜像/驱动组合分别完成支持的电源操作、风扇、自动续测、短测与长稳，保存原始报告；模拟结果不能替代硬件验收。

电源能力按本机检测，本机不支持 S3。风扇只适用于对应主板，显式选择后才执行控制。视频依赖 WMP ActiveX 和解码器。Core Temp 温度仅部分运行有数值，跨并行运行来源尚未绑定，未完成温度验收；GPU 温度统一采集尚未实现。采样不可用时保留空值和原因。详细限制与本次真实结果见《0.3.0修复与验收记录.md》。

用户数据位于 %LOCALAPPDATA%/GW.AgingTool。升级前结束任务并退出；安装保留配置、日志和检查点，迁移旧安装自带路径并保留显式外部覆盖。卸载保留用户数据，仅清理指向本安装的续测任务。旧检查点兼容读取，不凭历史 --resume 自动启动；使用旧 GUID 的待重启检查点无法核验新格式，需保留日志并新建任务。不要跨机器恢复活动检查点。
