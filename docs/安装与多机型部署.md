# 安装与多机型部署（0.2.0 复刻开发版）

运行 `GW_AgingTool_Setup_0.2.0_win-x64.exe`，可选全用户或当前用户安装。支持原生 x64 Windows 10 22H2 / Windows 11，内置 .NET 10。32 位、ARM64 仿真、旧系统及 Server 不在当前支持范围。

安装包包含从用户 GW_TEST 复制并校验的 Tools：BurnIn、PwrTest、Core Temp、视频、SFT、风扇和资源。新装自动匹配本安装目录，无需指向原开发目录。清单为 Tools/reuse-manifest.json。原包缺少 FurMark 和 3DMark 可执行引擎；场景定义不等于安装了引擎。第三方许可、目标机授权和驱动支持仍需符合各工具要求。

1. 打开兼容性检测和参数设置，确认本机项目及次数/时长。初始队列来自原 AgingSwitch，含 50 次重启/睡眠及一小时 BurnIn。
2. 真实电源操作用管理员启动。含重启/切项重启需勾选并保存“登录后续测”；系统重启后仍需本账户完成登录。
3. 点击底部“老化测试”，先预检整个队列再确认。菜单“老化队列与流程演练”中可主动选择演练，演练不验证硬件。
4. 每个型号/系统镜像/驱动组合分别做短测、支持的电源项目 3 轮和 50 轮，再做长稳，保存本机报告及原始结果。

Core Temp 1.17.1 为原包旧组件，新 CPU 可能无有效温度。S3/S4/CS 依赖 BIOS/系统；视频依赖 WMP ActiveX 和解码器。IP3/WB/Ed 为对应主板的风扇方案，显式选中后会控制硬件，不应给所有机型统一套用。

本轮没有执行真实重启、睡眠或风扇/EC 写入。此前一次 BurnIn 实测整轮失败，详见《真实短测结果_20261110》。本版本有实现和软件验证，不代表完整 1:1、全部机型或长稳已通过。

用户数据在 `%LOCALAPPDATA%/GW.AgingTool`。升级保留旧配置和路径，需要时重新匹配新安装的 Tools。不得把 active-run.json 复制到其他机器续测。同版本可修复安装，新版本以固定 AppId 升级；须先结束任务并退出。卸载保留用户日志、配置和检查点，仅清理本安装的续测任务及程序。
