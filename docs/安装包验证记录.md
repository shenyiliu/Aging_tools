## 多型号验收

本版安装策略允许 Windows 10 22H2（19045）及 Windows 11 原生 x64 客户端，拒绝 ARM64、32 位、旧 Windows 和 Server。系统策略有 8 组自动测试，实际安装只在上述 Windows 11 环境验证。

部署到每个型号后，先从开始菜单打开“本机兼容性检测”并导出报告，再配置本机工具路径，执行模拟和真实预检。按机型、BIOS、系统镜像、驱动版本分别记录短测、3 轮、50 轮及长稳结果。未执行真实重启、睡眠、压力测试和风扇驱动测试，不能将本记录当作这些项目通过的证明。

温度桥、厂商风扇和专用压力引擎适配仍有未完成项；第三方引擎需要单独配置及验证。本机报告已区分硬件不支持、依赖缺失、尚未适配和可继续预检的项目。完整部署步骤见 `安装与多机型部署.md`。

## 复验入口

```powershell
.\scripts\build.ps1
.\scripts\build-installer.ps1
.\scripts\verify-installer.ps1
# 已提权，且不存在真实安装时：
.\scripts\verify-installer.ps1 -AllUsers -BaselineSetup <旧版测试安装包的绝对路径>
.\scripts\verify-release.ps1
```

验证脚本检测到已有真实安装时会停止，避免覆盖日常使用的数据与程序。测试只使用独立目录。若本机全局 NuGet 缓存被其他进程占用，可给 `build-installer.ps1` 传入 `-PackagesDirectory <独立缓存目录>`，无需更改系统防护或删除全局缓存。
