## 构建与验证方式

组件导入可重复执行：`scripts/copy-reference-tools.ps1 -ReferenceRoot C:\Users\a\Desktop\GW_TEST`。

`scripts/verify-tools.ps1 -VerifySource` 核验全部复制文件与来源、生成文件、关键依赖、总字节数和配置范围。`scripts/publish.ps1` 在构建发布前自动验证组件，图标也使用项目自己的组件目录，避免依赖上级目录中的旧 GW_TEST。

发布目标为 Windows 原生 x64，采用项目现有自带 .NET 运行时的 Inno Setup 安装器。ZIP 内包含安装 EXE、使用说明、本记录和 SHA256 清单；外部同名 `.zip.sha256` 校验整个 ZIP。

本次不将历史硬件测试结论视为当前机器的实测结果。组件静态核验和软件流程验证不等于硬件压力、重启、睡眠或风扇实机验收。实际构建与验证结果保存在项目 `artifacts/verification`。
