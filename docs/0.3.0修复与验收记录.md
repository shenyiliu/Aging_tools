## 监测、差异与待验收

每三秒保存 `load-telemetry.tsv`，同时保留旧格式 `GW_CoreTemp.log`。CPU 使用系统时间差、内存使用原生状态、磁盘使用 PDH 忙碌率和吞吐、GPU 按物理引擎汇总进程后取最忙引擎，原始引擎数据保留。Unavailable 不用零伪装。

负载曲线和统计在 `artifacts/acceptance/20261112-load-curves.svg`、`20261112-load-summary.json`。计数器为系统级，并非本轮进程专属；mode2 最后约一分半与首轮 FurMark 重叠，FurMark 复测期间还发生短视频回归，不能将所有系统 GPU 波动归于单一负载。Core Temp 在 mode0/1 和 FurMark 复测不可用，但 mode2 原始日志有128个温度数值（41.3–97.3℃），首轮 FurMark 也有部分数值后转为不可用。跨并行运行的传感器来源尚未绑定，记录数值但不宣称连续可靠温度验收。FurMark CSV GPU 温度为 0.0（不当作真实温度），GPU 温度统一采集尚未实现。BurnIn 自身磁盘温度行另保留，不冒充 CPU/GPU 温度。
