# GMK 老化测试工具 0.2.5 — 原版模块复刻开发版

以用户提供的 GW_TEST 5.0.0818 为基准，使用 REA 核对 PE 资源、文件身份及 BurnIn 依赖，结合已恢复 AutoIt 脚本实现老化业务。恢复脚本来自独立 AutoIt-Ripper，不冒充 REA 反编译结果。尚未完成原版运行截图的逐像素对照，不能宣称全部机型和项目已 1:1 通过。

0.2.3 将软件名称统一为“GMK 老化测试工具”，采用 GMKtec 官网 Logo 与图标，更新窗口、托盘、EXE 元数据、安装向导和快捷方式。

0.2.5 增加安装前文件替换权限/占用检查，避免错误 32 发生后留下混合版本。安装目录页始终可见，允许在原目录被系统服务占用时选择新的空目录。详见《0.2.5安装错误32修复记录》。

## 安装与使用

解压 `artifacts/installer/GMK_AgingTool_Setup_0.2.5_win-x64.zip`，运行其中的 `GMK_AgingTool_Setup_0.2.5_win-x64.exe`。支持 Windows 10 22H2 / Windows 11 原生 x64，自带 .NET 10。安装本身不执行老化或注册自动续测。

0.2.2 修复真实老化启动流程：逐项显示依赖和电源能力，允许明确选择本轮项目；含重启时在最终确认后自动登记并验证登录续测。未执行项目会写入日志，不计为通过。默认 BurnIn 已切换为重装目录中实际完成六分钟综合测试的引擎。详见《0.2.2修复与验收记录》。

原包中 313 个现有组件文件已复制到本工具自己的 `Tools` 并逐个校验 SHA256。包含 BurnIn 9.2 引擎、原配置和依赖、PwrTest、Core Temp、视频/SFT、风扇方案及图片/语言/3DMark 定义。新安装自动使用自己目录的组件，运行不要求保留原 GW_TEST。复用清单在 `Tools/reuse-manifest.json`；第三方许可和目标机授权仍沿用各工具自己的规则。

首次使用保留原 AgingSwitch 队列和参数。请检查本机适用项目、次数与时长；原队列含 50 次电源测试和一小时 BurnIn。含重启/切项重启需管理员启动。0.2.5 移除登录续测的查询、注册和强制预检；重启后手动打开工具，点击“恢复任务”继续。旧 --resume 参数同样不会自动运行测试。

底部“老化测试”启动真实队列，运行中点击查看当前项目。悬停显示原 94 像素宽状态浮层，点击行查看项目。菜单“老化队列与流程演练”提供扩展面板；只有主动勾选“仅演练”才跳过硬件，演练不能产生硬件 PASS。开始前逐项检测依赖，允许明确选择本轮项目并要求最终确认。

配置、检查点和日志位于 `%LOCALAPPDATA%/GW.AgingTool`。升级保留已有设置与自选路径，可在路径页重新匹配新安装的 Tools。不要把活动检查点复制到其他机器续测。

## 本轮实现

- 项目编辑窗恢复原脚本尺寸、标签、候选及菜单，Video 唯一置末并与完成关机互斥。
- 独立 700×360 重启、720×370 睡眠窗口，显示调度状态、倒计时、周期、错误及信息。
- 重启/睡眠各自的均值比较、睡眠短时长检查、暂停耗时和旧日志本地时间戳。
- 视频全屏 16:9、顶部时间/电池浮层和 P/F 点击显隐；PlayNum 统计进入测试次数。
- BurnIn 模式 0/1/2 使用原 bitcfg 和隔离引擎副本，核对原始报告、时长、CPU/RAM 或磁盘行及退出码。
- Core Temp 真实共享内存采集；无有效传感器数据时显示未获取。
- IP3/WB/Ed 风扇在用户选定方案后，于重启前倒计时期间调用私有副本，退出或取消后有界执行恢复并留存输出。仅在私有运行脚本修正原条件和等待错误。
- 日志恢复状态横条、功能/老化双栏及红温度/绿 CPU 曲线；中止、不确定及演练不能凭 END 判硬件通过。
- 下次开机开始使用持久等待状态及真实启动 GUID；仅重开程序不触发。此选项等待手动开机，不复制原版立即强制关机。
- 测试时最大音量按显式设置执行，正常结束或请求重启前恢复；用户运行中手动改音量时保留用户选择。异常断电/强制结束后的恢复仍需专机验证。

## 验证边界

66 项 Core、19 项 Windows 单元测试全部通过。5 项软件 E2E 覆盖启动选择、检测中取消、八模块演练、真实视频失败及停止；演练明确不计硬件通过。本轮另通过真实启动入口运行 BurnIn 综合模式 6 分 02 秒，CPU、GPGPU、RAM、2D、3D、声音、视频和 C 盘均 PASS、0 错误。此前旧引擎磁盘异常的 FAIL 记录仍保留，不能用本次 PASS 覆盖历史。CPU Core Temp 仍无有效温度。本轮未执行风扇、真实重启/睡眠或最大音量切换；电源验收待单独授权。

重装后已找到并备份三个压力包装器；FurMark/3DMark 可执行引擎仍缺失，现有语言/场景定义不能代替它们，缺失项目会被预检阻止。各 CPU 温度、各主板风扇、真实电源、停止恢复、DPI 与长稳仍需目标机验收。订单、OA3、出货封装不属于本老化模块；不以关闭 UAC 或全局清日志等原版副作用作为复刻条件。

详见 `原版老化行为对照_20261110.md`、`厂商风扇适配.md`、`CoreTemp温度桥接.md`、`真实短测结果_20261110.md`。

## 构建

安装 .NET SDK 10 与 Inno Setup，依次运行 `scripts/copy-reference-tools.ps1`、`scripts/build.ps1`、`scripts/build-installer.ps1`。`--smoke <目录>` 只运行独立短队列演练并截图，不改变正式队列或执行电源/负载。`--compatibility-report <文件>` 导出本机能力，不替代硬件验收。
