# GMK 老化测试工具 0.3.4

基于本机 GW_TEST 5.0.0818 的老化模块，在现有 C# / .NET 10 WinForms 项目上恢复功能行为。仅提供 Reboot、S3、S4、CS、BurnIn、FurMark、3DMark、Video、队列、续测和日志；软件账号、后管、功能测试、SN/OA3 不属于本工具。

REA 核验了主程序及七个相关模块的文件身份和资源；AutoIt 脚本由独立 AutoIt-Ripper 1.2.0 静态恢复。两类证据分别保存于 artifacts/reverse/20261112，没有将脚本恢复冒称为 REA 反编译。逐项依据及差异见《原版老化行为对照_20261112.md》。

## 安装与启动

使用 artifacts/installer/GMK_AgingTool_Setup_0.3.4_win-x64.exe，或先完整解压同名 ZIP。目标为 Windows 10 22H2 / Windows 11 原生 x64，自带 .NET 10 运行时。已在本机与 GMKtec EVO-X2（Windows 11）测试；Windows 10 与其他硬件组合待验收。

0.3.4 主程序和七个模块入口默认请求管理员权限，双击 EXE、快捷方式或从安装完成页启动时由 Windows 显示 UAC 授权提示；取消授权不会进入程序。使用当前用户提升权限，普通账户需提供管理员凭据；不切换到内置 Administrator，不关闭 UAC。命令行探针和自动化调用同样需要已提权的运行环境。重启续测继续使用绑定用户、最高权限的计划任务。

安装包含自己的 Tools，不依赖桌面 GW_TEST。组件清单 Tools/reuse-manifest.json 保存来源、大小及 SHA256；只发布清单内的老化组件，不夹带历史 SFT 程序或注册命令。保留原始压力包装器作为参照，正式运行由宿主统一调度。

首次保留原 INI 队列。原队列有多次电源操作及长时间压力测试，开始前检查项目、次数、时长。“老化测试”打开逐项预检和本轮选择；取消的项目记录为未执行。仅做负载时关闭切项重启、下次开机开始，按需要关闭最大音量。启动时已请求电源和 BurnIn 等项目所需的管理员权限。常规设置只需选择引擎文件，无需填写 JSON。

含跨重启流程时，在最终确认后登记当前 Windows 用户的计划任务，进入该用户桌面后继续，无需软件账号。续测绑定任务、安装路径、数据目录、用户和系统启动标识；同一次开机重复打开不增加周期。完成或终止后清理计划任务。旧检查点兼容读取但不会仅凭旧 --resume 参数自动运行；使用旧 GUID 标识的待重启任务无法与新格式核验，需保留日志并新建任务。

配置、检查点及日志默认在 %LOCALAPPDATA%/GW.AgingTool。升级迁移原安装自带组件路径并保留显式外部路径。不要跨机器复制活动检查点。升级前结束任务、退出软件；卸载保留用户数据。

## 当前实现与结果

- 0.3.1 修复工具栏图片早于按钮释放引发的 `Parameter is not valid` 绘制异常；首次命令行兼容性报告使用与正常启动一致的组件发现和迁移规则，检测不改写用户配置。目标机验证记录见《目标机测试与修复_20261113.md》。
- 修复重复显示状态浮层/兼容性窗口引发的窗体异常，启动失败显示具体原因。
- BurnIn 9.2.1006.0 保留三份原配置：综合、综合(DX9)、硬盘；新增 DDR Test（内存）独立模式，可从新建菜单或 BurnIn 模式选择。DDR 使用标准循环内存测试，只运行 Memory，报告中出现其他负载、缺少有效操作数或存在错误都不能通过。测试限于 Windows 可用物理内存，不覆盖固件或 GPU 保留区域。
- S3/S4 使用 PwrTest 规定的 `/h:y`、`/h:n` 参数，并关闭重复的引擎倒计时。核对本轮配对的系统事件、实际电源状态和睡眠时长；不支持 S3 的机器明确拦截，不用 Modern Standby 代替。续测计划任务使用正常优先级。
- 真实压力和视频执行期间申请保持系统及显示运行，结束后释放，防止空闲 Modern Standby 中断测试。0.3.3 用持久化内核启动事件识别真实重启，修复目标机重启后旧 GUID 不变导致无法续计的问题；缺少有效启动事件或标识格式不匹配时不增加周期。
- 独立启动引擎副本，保存命令、版本、SHA256、stdout/stderr 和原始报告。进程挂起创建并加入本轮 Job 后再运行，启动器退出后继续跟踪其负载子进程；取消和超时只终止本轮进程树。
- FurMark 1.30.0.0 专用适配分辨率、抗锯齿、窗口及毫秒时长。开发环境已取得并冻结官方文件；其 EULA 商用/打包许可未提供，发布包只含适配器及来源说明，需提供获授权的匹配引擎。
- 3DMark 七个场景专用适配已实现；有效商业授权和匹配引擎未提供，真实验收未完成。3DMark11 输出参数仍需匹配授权版本实测。
- 每三秒记录 CPU、GPU 各引擎、内存、磁盘吞吐/忙碌率，保留原始 TSV。Core Temp 温度仅部分运行有数值，跨并行运行来源尚未绑定，未完成温度验收；GPU 温度统一采集尚未实现。
- 2026-11-12 正式界面真实 BurnIn：综合 6分03秒 FAIL（3D Graphics / Unknown DirectX error），综合(DX9) 6分04秒 PASS，硬盘 PASS。FurMark、视频、软件回归及剩余验收见《0.3.0修复与验收记录.md》。

2026-11-13 目标 EVO-X2 已完成真实压力、内存和电源专项测试。S3 不支持；S4 曾通过，但复测出现 ACPI BIOS 错误和 HDMI 音频端点丢失；重启后的正式程序自动续计已修复，整轮仍因系统错误事件判失败。逐轮结果见《目标机测试与修复_20261113.md》，不能据此宣称全部电源老化稳定。视频 P/F/停止按钮回归不代替人工视觉和音频验收；风扇和长稳仍待验收。FurMark/3DMark 的执行完成或有效分数不等同硬件稳定性 PASS。

## 构建

安装 .NET SDK 10 和 Inno Setup 后依次运行 scripts/copy-reference-tools.ps1、scripts/verify-tools.ps1 -VerifySource、scripts/build.ps1、scripts/build-zip.ps1、scripts/verify-zip.ps1。--smoke <目录> 使用独立数据目录执行界面演练，不执行真实负载或电源；--compatibility-report <文件> 导出只读能力报告。
